# Portfolio Project | Sahib Dino

A professional data analyst portfolio website built with HTML, CSS, and JavaScript.
Designed to align with a "Premium Dark" aesthetic, highlighting data science projects and business analytics experience.

## Features
*   **Premium Dark UI**: Glassmorphism cards and neon accents.
*   **Responsive Design**: Fully mobile-friendly.
*   **Project Showcase**: Detailed analytics projects (Google Fiber, IBM HR, etc.).

## Tech Stack
*   HTML5
*   CSS3 (Custom Properties, Flexbox, Grid)
*   JavaScript (Intersection Observer for animations)
